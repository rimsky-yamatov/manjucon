満州語 文法の基本

入門トップ　単語一覧　変換ツール
ここに書いたのは、文語満州語の基本的な規則を簡略化したものです。例外が多い項目は「語により異なる」と書いて詳細を省きました。例文は文法に沿って組んだ作例で、実際の文献の引用ではありません。確かめるには、津曲敏郎『満洲語入門20講』や Gorelova『Manchu Grammar』、Norman の満英辞典などを参照してください。

1. 全体像

語順は主語・目的語・動詞（SOV）で、動詞は文末に置きます。修飾語は修飾される語の前に置き、助詞は名詞のうしろにつく後置詞です。書字は上から下へ、行は左から右へ進みます。

2. 母音調和

分類母音
男性（陽）a　o　ū
女性（陰）e
中性i　u

語尾につける接尾辞の母音は、語幹の母音に合わせて選ばれます（たとえば過去の -ha / -he / -ho）。k・g・h は、後ろの母音が a o ū か e i u かで字形が変わります（字形は変換ツールで確認できます）。

4. 名詞につく助詞（格）

はたらき形例
主格無標bi
属格（〜の）i ／語末が母音のとき nimanju gurun i bithe（満洲国の書）
対格（〜を）bebithe be hūlambi（書を読む）
与位格（〜に・〜で）deboo de bi（家にいる）
奪格（〜から・〜より）cialin ci wasimbi（山から下りる）
具格（〜で・手段）iberi i gabtambi（弓で射る）

複数は、語によって -sa / -se / -ta / -te / -ri などの接尾辞がつき、規則は語ごとに違います。geren（衆）を前に置いて「geren niyalma（多くの人々）」のように言う方法も多く使われます。

5. 動詞の活用（jimbi「来る」の例）

形活用意味
辞書形・現在未来jimbi来る
過去jihe来た（過去分詞でもある）
完了（確認）jihebi来ている・来た
過去の継続jimbihe来ていた
現在否定jirakū来ない
過去否定jihe akū来なかった
命令jio来い（不規則なので語ごとに覚える）
願望・意志jiki来たい・来させよ
連用（並列・同時）jime来て・来ながら
連用（完了後）jifi来てから
条件jici来るならば
連体（現在未来）jire来る〜（jire niyalma）

語幹末や母音調和で、-ha / -he / -ho、-ra / -re / -ro などと形が変わります。命令形は、tuwa（見よ）、gene（行け）、te（座れ）のように語ごとの形が多く、丁寧な依頼には -su がつきます（gaisu「お取りください」）。

5-2. 時制と接続の整理

意味形例（jimbi）
現在・未来-mbi（専用の未来形はない）jimbi（来る・来るだろう）
過去-ha / -he / -ho / -ka / -ke / -kojihe（来た）
完了・確認過去形 ＋ bi（-habi など）jihebi（来ている）
過去の継続-mbihejimbihe（来ていた）
意志・願い-kijiki（来よう・来たい）
推量文末に dere（〜だろう）jimbi dere
同時・並列-mejime
完了してから-fijifi
条件（〜ならば）-cijici
譲歩（〜ても）-cibejicibe
〜のとき連体形 ＋ dejire de
〜した後過去形 ＋ manggijihe manggi
〜する前連体形 ＋ onggolojire onggolo
〜ので連体形 ＋ jakadejire jakade
使役・受身-bu-tacimbi（学ぶ）→ tacibumbi（教える）

過去形の語尾は語幹の母音で -ha / -he / -ho、さらに -ka / -ke / -ko に分かれ、語ごとに異なります（jembi の過去 jeke など）。下の表で確認してください。語幹は辞書形から -mbi を取ったもので、-me / -fi / -ci / -ki はそのままつけられます（genembi → geneme, genefi, genici）。

5-3. 主な動詞の活用表

辞書形（意味）過去連体命令-fi-ci

連体は「〜する（現在未来）」の形です。sambi の否定は sarkū、gaimbi の命令は gaisu など、不規則な形があります。

6-2. 序数と年月日

項目形例
序数基数 ＋ -ci（語末の n は落ちるのが普通）ilan → ilaci（第三）、duin → duici（第四）、sunja → sunjaci（第五）
第一・第二特別な語uju（第一）、jai（第二）
月基数 ＋ biyailan biya（三月）、juwan emu biya（十一月）
日（一〜十日）ice ＋ 基数ice sunja（五日）
年（年号）年号 ＋ i ＋ 序数 ＋ aniyaelhe taifin i ilaci aniya（康熙三年）
月日月 ＋ 日 ＋ de（〜に）ilan biya ice sunja de（三月五日に）

11日以降の言い方や、年号の元年の言い方は文献により異なるため、ここでは省きました。年号は、康熙＝elhe taifin、雍正＝hūwaliyasun tob、乾隆＝abkai wehiyehe などです（単語一覧にあります）。

7. 修飾

形容詞は名詞の前に置きます（amba boo「大きな家」）。名詞が名詞を修飾するときは属格 i をつけます。動詞の連体形（-re / -ha / -he）も名詞の前に置いて修飾します（jihe niyalma「来た人」）。
